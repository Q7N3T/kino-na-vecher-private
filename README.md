# Кино на вечер

Сайт, который помогает выбрать фильм или сериал на сегодняшний вечер.

**Сайт:** https://q7n3t.github.io/kino-na-vecher-private/

## Идея

Вечером человек обычно знает несколько вещей: сколько у него есть времени, какое у него настроение и хочется ли ему фильм или сериал. Поэтому выбор начинается не с жанров и фильтров, а с одной фразы:

> Сегодня у меня **полтора часа**, хочется **посмеяться**. Смотрим **сериал**

Выделенные слова можно поменять, и подборка обновится сразу. На каждой карточке видно, во сколько закончится фильм или серия, если начать прямо сейчас.

## Разделы

- **Главная** — фраза-подбор, «Выбор на сегодня» с кубиком случайного выбора, подборки, популярное.
- **Фильмы и Сериалы** — каталог с фильтрами по длительности, настроению, жанру, годам и статусу сериала; сортировка «Популярное», «Высокий рейтинг», «Новинки».
- **Страница фильма или сериала** (`/film/…/`, `/serial/…/`) — постер, рейтинг IMDb, сезоны и серии, статус сериала, время окончания, описание, актёры с фото, похожее.
- **Актёры** (`/akter/…/`) — фото и фильмография; страница есть у тех, кто снимался хотя бы в трёх тайтлах базы.
- **Подборки**, **Поиск** (по названию, актёру, режиссёру), **Мой список** (пока в браузере).

У каждого фильма, сериала и актёра своя страница — их индексируют поисковики.

## Данные

База собирается скриптом `scripts/build_films.py` и лежит в `data/films.js` (основные данные) и `data/syn/*.json` (описания, состав, сезоны).

- **IMDb** (открытые датасеты): названия, в том числе русские прокатные, годы, длительность, жанры, рейтинг, режиссёры, сезоны и серии. Фильмы, сериалы и мини-сериалы, у которых не меньше 10 000 оценок; ток-шоу и новости не берутся. Считаются только вышедшие серии — анонсированные сезоны IMDb заводит заранее.
- **TMDB** (с ключом `TMDB_API_KEY`): постеры, описания, состав с фото, популярность, статус сериала.
- **Настроения** («посмеяться», «понервничать», «погрустить», «подумать», «вдохновиться») выводятся из жанров.

## Подбор на главной

`src/lib/curate.js` собирает 12 карточек «Подходит на сегодня» не по популярности, а из нескольких источников:

- **находки** — высокий рейтинг при небольшой известности (с русским названием и от 20 тыс. оценок, чтобы отсеять накрученное); меняются каждый день;
- **свежее** — последние пять лет, хорошо оценено и на слуху;
- **классика** — до 2000 года, рейтинг от 7,8;
- **по вашему вкусу** — если есть история (`src/lib/taste.js`: открытые страницы, «Мой список», «Смотрю сегодня» хранятся только в браузере).

Учитывается, насколько настроение главное в тайтле и насколько длительность заполняет свободное время. Одна франшиза — одно место, похожие подряд не идут. «Выбор на сегодня» — обычно находка, меняется в полночь.

Кубик на карточке «Выбор на сегодня» — случайный тайтл под ту же фразу (время, настроение, фильм или сериал): только хорошо оценённые (IMDb от 7, от 25 тыс. оценок), последние 30 выпавших не повторяются; «← Выбор дня» возвращает выбор дня.

## Где посмотреть

На странице тайтла — легальные онлайн-кинотеатры в России (подписка, бесплатно, аренда, покупка) по данным JustWatch через TMDB. Сервисы Яндекса не показываются.

```
python3 scripts/build_films.py                  # собрать базу из IMDb
python3 scripts/build_films.py --min-votes 25000  # другой порог по числу оценок
TMDB_API_KEY=… python3 scripts/build_films.py --tmdb  # добавить данные TMDB
```

Information courtesy of IMDb (https://www.imdb.com). Used with permission. Датасеты IMDb разрешены только для личного некоммерческого использования.

This product uses the TMDB API but is not endorsed or certified by TMDB.

## Сайт

[Astro](https://astro.build), статическая сборка: каждая страница собирается заранее, сервер не нужен.

```
npm install
npm run build     # собрать в dist/
npm run preview   # посмотреть локально
npm test          # тесты: подбор, форматирование, сборщик базы (Node и Python, без зависимостей)
```

Постеры и фото TMDB идут через прокси `wsrv.nl`: `image.tmdb.org` открывается не везде, в том числе в России.

## Обновление и выкладка

- `.github/workflows/update-films.yml` — по понедельникам пересобирает базу из IMDb и TMDB и коммитит её.
- `.github/workflows/deploy.yml` — собирает сайт и выкладывает на GitHub Pages после каждого пуша в `main` и после обновления базы. В настройках репозитория: Settings → Pages → Source: **GitHub Actions**.

## Структура

```
src/pages/               — страницы сайта
src/components/          — страница тайтла, каталог
src/lib/data.js          — чтение базы при сборке, похожие, подборки, актёры
src/lib/format.js        — форматирование и карточка (общие для сборки и браузера)
src/lib/client.js        — индекс, фильтры и «Мой список» в браузере
data/                    — база (генерируется)
scripts/build_films.py   — сборка базы из IMDb и TMDB
```
