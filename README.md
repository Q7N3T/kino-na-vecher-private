# Кино на вечер

Прототип веб-сервиса, который помогает выбрать фильм для просмотра сегодня вечером.

**Открыть прототип:** https://q7n3t.github.io/kino-na-vecher-private/

## Идея

Вечером человек обычно знает две вещи: сколько у него есть времени и какое у него настроение. Поэтому выбор начинается не с жанров и фильтров, а с одной фразы:

> Сегодня у меня **около полутора часов**, и хочется **посмеяться**

Выделенные слова можно поменять, и подборка обновится сразу. А на каждой карточке видно, во сколько закончится фильм, если начать прямо сейчас.

## Страницы

**Каталог**
- фраза-фильтр по времени и настроению;
- подборка под вечер, отсортированная по рейтингу IMDb, с подгрузкой при прокрутке;
- поиск по всей базе: по названию (русскому или оригинальному), режиссёру или актёру;
- время окончания каждого фильма;
- кнопка «Выбрать за меня» — случайный фильм из подходящих.

**Страница фильма**
- постер, год, режиссёр, длительность, рейтинг и число оценок IMDb;
- время окончания, если начать сейчас;
- описание (если есть в TMDB), настроения и жанры;
- актёры и их роли;
- поиск трейлера и ссылка на страницу IMDb;
- кнопка «Смотрю сегодня» — выбор сохраняется и показывается в каталоге;
- похожие фильмы.

## Данные

База собирается скриптом `scripts/build_films.py` из открытых датасетов IMDb (https://developer.imdb.com/non-commercial-datasets/) и сохраняется в `data/films.js`. В базу попадают полнометражные фильмы, у которых на IMDb не меньше 25 000 оценок.

- из IMDb: названия (включая русские прокатные), год, длительность, жанры, рейтинг, режиссёры, актёры;
- из TMDB (если задан ключ): постеры, русские названия и описания. Без ключа вместо постеров показываются заглушки;
- настроения («посмеяться», «понервничать», «погрустить», «подумать», «вдохновиться») выводятся из жанров IMDb автоматически.

```
python3 scripts/build_films.py                  # собрать базу из IMDb
python3 scripts/build_films.py --min-votes 50000  # другой порог по числу оценок
TMDB_API_KEY=… python3 scripts/build_films.py --tmdb  # добавить постеры и описания
```

Information courtesy of IMDb (https://www.imdb.com). Used with permission. Датасеты IMDb разрешены только для личного некоммерческого использования.

## Технологии

HTML, CSS и JavaScript без фреймворков и сборки: `index.html` и файл данных `data/films.js`. Шрифты Unbounded и Golos Text подключены из Google Fonts. Сайт размещён на GitHub Pages.

## Структура

```
index.html               — весь интерфейс
data/films.js            — база фильмов (генерируется)
scripts/build_films.py   — сборка базы из IMDb и TMDB
```
