# Кино на вечер

Прототип веб-сервиса, который помогает выбрать фильм для просмотра сегодня вечером.

**Открыть прототип:** https://q7n3t.github.io/kino-na-vecher/

## Идея

Вечером человек обычно знает две вещи: сколько у него есть времени и какое у него настроение. Поэтому выбор начинается не с жанров и фильтров, а с одной фразы:

> Сегодня у меня **около полутора часов**, и хочется **посмеяться**

Выделенные слова можно поменять, и подборка обновится сразу. А на каждой карточке видно, во сколько закончится фильм, если начать прямо сейчас.

## Страницы

**Каталог**
- фраза-фильтр по времени и настроению;
- фильмы, которые подходят под вечер, и остальная коллекция ниже;
- время окончания каждого фильма;
- кнопка «Выбрать за меня» — случайный фильм из подходящих.

**Страница фильма**
- постер, год, страна, режиссёр, длительность, возрастной рейтинг;
- время окончания, если начать сейчас;
- логлайн, синопсис и настроение фильма;
- рейтинги Кинопоиска и IMDb, актёры, награды, темы;
- трейлер на Кинопоиске;
- кнопка «Смотрю сегодня» — выбор сохраняется и показывается в каталоге;
- фильмы с похожим настроением.

## Данные

Информация о фильмах и постеры взяты из материалов тестового задания (`movies.json`). Разметка по настроениям («посмеяться», «понервничать», «погрустить», «подумать», «вдохновиться») составлена вручную на основе описаний настроения и жанров.

## Технологии

Один файл `index.html` на HTML, CSS и JavaScript без фреймворков и сборки. Постеры лежат в папке `posters`. Шрифты Unbounded и Golos Text подключены из Google Fonts. Сайт размещён на GitHub Pages.

## Структура

```
index.html   — весь прототип
posters/     — постеры фильмов
```
