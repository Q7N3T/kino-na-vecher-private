# Кино на вечер

Прототип веб-сервиса, который помогает выбрать фильм или сериал на сегодняшний вечер.

**Открыть прототип:** https://q7n3t.github.io/kino-na-vecher-private/

## Идея

Вечером человек обычно знает несколько вещей: сколько у него есть времени, какое у него настроение и хочется ли ему фильм или сериал. Поэтому выбор начинается не с жанров и фильтров, а с одной фразы:

> Сегодня у меня **около полутора часов**, и хочется **посмеяться**. Смотрим **сериал**

Выделенные слова можно поменять, и подборка обновится сразу. А на каждой карточке видно, во сколько закончится фильм или серия, если начать прямо сейчас. Для сериалов время считается по одной серии, а на странице сериала видно, сколько серий успеете за вечер.

## Страницы

**Каталог**
- фраза-фильтр по времени, настроению и типу (фильм, сериал или что угодно);
- подборка под вечер: сначала популярное, как на TMDB, или по рейтингу, или новинки; 10 карточек сразу, остальные по кнопке «Показать ещё»;
- поиск по всей базе: по названию (русскому или оригинальному), режиссёру или актёру;
- время окончания каждого фильма;
- кнопка «Выбрать за меня» — случайный фильм или сериал из лучших подходящих.

**Страница фильма или сериала**
- постер, год (для сериала — годы выхода, сезоны и серии), режиссёр, длительность, рейтинг и число оценок IMDb;
- время окончания, если начать сейчас, а для сериала — сколько серий успеете;
- описание (если есть в TMDB), настроения и жанры;
- актёры и их роли;
- поиск трейлера и ссылка на страницу IMDb;
- кнопка «Смотрю сегодня» — выбор сохраняется и показывается в каталоге;
- похожие фильмы и сериалы.

## Данные

База собирается скриптом `scripts/build_films.py` из открытых датасетов IMDb (https://developer.imdb.com/non-commercial-datasets/) и сохраняется в `data/films.js`. В базу попадают полнометражные фильмы, сериалы и мини-сериалы, у которых на IMDb не меньше 10 000 оценок: около 12 600 фильмов и 2 800 сериалов.

- из IMDb: названия (включая русские прокатные), годы, длительность, жанры, рейтинг, режиссёры, актёры, число сезонов и серий;
- из TMDB (если задан ключ): постеры, русские названия и описания. Без ключа вместо постеров показываются заглушки;
- популярность: если база собрана с TMDB, берётся их показатель popularity, и порядок совпадает с themoviedb.org; без TMDB — приближение по IMDb (число оценок с поправкой на давность выхода);
- настроения («посмеяться», «понервничать», «погрустить», «подумать», «вдохновиться») выводятся из жанров IMDb автоматически.

```
python3 scripts/build_films.py                  # собрать базу из IMDb
python3 scripts/build_films.py --min-votes 25000  # другой порог по числу оценок
TMDB_API_KEY=… python3 scripts/build_films.py --tmdb  # добавить постеры и описания
```

Information courtesy of IMDb (https://www.imdb.com). Used with permission. Датасеты IMDb разрешены только для личного некоммерческого использования.

## Технологии

HTML, CSS и JavaScript без фреймворков и сборки: `index.html` и файл данных `data/films.js`. Шрифты Unbounded и Golos Text подключены из Google Fonts. Сайт размещён на GitHub Pages.

## Структура

```
index.html               — весь интерфейс
data/films.js            — база фильмов и сериалов (генерируется)
scripts/build_films.py   — сборка базы из IMDb и TMDB
```
